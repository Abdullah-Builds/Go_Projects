A collection of beginner-friendly Go projects showcasing core backend development concepts, including REST APIs, concurrency, and SMTP email services.

## 📂 Projects

### 🌐 REST API
A simple RESTful API built with Go that demonstrates HTTP routing, JSON handling, and CRUD operations.

**Features**
- RESTful endpoints
- CRUD operations
- JSON request/response
- Clean project structure

---

### 📧 Email Dispatcher
A concurrent email dispatching service built with Go using goroutines, channels, and SMTP.

**Features**
- Concurrent email sending
- Worker pool implementation
- SMTP integration
- Error handling & logging

## 🛠️ Tech Stack

- Go
- REST API
- Goroutines & Channels
- SMTP
- JSON

## 🚀 Getting Started

```bash
git clone https://github.com/Abdullah-Builds/Go_Projects.git
cd Go_Projects
```

Then navigate to the project you want to run:

```bash
cd RESTAPI
# or
cd Email_Dispatcher

go mod tidy
go run main.go
```

## 📚 Purpose

These projects were built to practice Go fundamentals, backend development, concurrency, and building real-world applications.
